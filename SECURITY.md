# Documentation security policy

This repository contains deployment guidance and examples. Security issues in the Plainwire application itself belong in the upstream Plainwire security channel.

For this handbook, report instructions that can cause credential disclosure, public database exposure, unsafe TURN relay configuration, destructive backup behavior, broken access control assumptions, or another reproducible deployment risk.

Do not include live credentials, private keys, database contents, or user data in a report. Reproduce with placeholders.
