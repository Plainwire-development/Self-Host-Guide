# Notice

This repository is the self-hosting and operations handbook for Plainwire 2.1. It does not contain the Plainwire application source tree.

The current handbook target is Plainwire 2.1.0, refreshed on 2026-09-19. Selected upstream configuration examples are retained under `examples/upstream-2.1.0/`. The earlier `examples/upstream-2.0.0/` directory remains as a historical comparison aid for operators upgrading from 2.0.

The handbook examples are operator-oriented starting points, not a substitute for reviewing the matching Plainwire source, release notes, and local infrastructure policy.
