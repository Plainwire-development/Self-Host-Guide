# Notice

This repository is the self-hosting and operations handbook for Plainwire 2.5. It does not contain the Plainwire application source tree.

The current handbook target is Plainwire 2.5.0, refreshed on 2026-09-22. Selected upstream configuration examples are retained under `examples/upstream-2.2.0/`. The earlier `examples/upstream-2.1.0/` and `examples/upstream-2.0.0/` directories remain as historical comparison aids for operators upgrading older installations.

The handbook examples are operator-oriented starting points, not a substitute for reviewing the matching Plainwire source, release notes, and local infrastructure policy.
