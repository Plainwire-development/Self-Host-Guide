# Repository scope

This repository is the self-hosting and operations handbook for Plainwire 2.0. It does not contain the Plainwire application source tree.

The handbook was prepared against a Plainwire 2.0.0 source snapshot supplied on 2026-09-17. Selected upstream configuration examples are retained under `examples/upstream-2.0.0/` so operators can distinguish upstream defaults from the handbook's opinionated production examples.

Plainwire is licensed under GNU AGPL version 3 in the supplied source snapshot. The license text is included as `LICENSE`.
